# data10-04 · 이은학

> 패들릿에 올라온 과제 접수 글을 옮겨 적었습니다. 회사 이름은 리포에 남기지 않기로 해 「회사명 생략」으로 적었습니다.

## 게시물 · 개발장비 외관평가 Agent

① 직무·소속 : (회사명 생략) 선행품질파트

② 현안 : 개발장비 외관검사 체크 시트에 실제 이슈 발생 빈도 반영

③ 보유 데이터 : 개발장비 외관검사 체크시트, 개발장비 외관검사 이슈 리스트

④ 기대 산출물 : 개발모델에 따른 외관검사 체크시트 최적화 및 이슈 발생 우려 포인트 산출

## 강사 답글로 요청한 것 (기획서 10장)

1. 지금 쓰는 외관검사 체크시트 양식(항목 목록)
2. 이슈 리스트 몇십 행(모델·부위·이슈 내용·발생일)
3. 개발모델을 나누는 기준(기종·크기·신규 부품 여부)
4. 지금 우려 포인트를 정하는 판단 기준·우선순위 방식

체크시트 항목과 이슈를 잇는 공통 키(부위명 등)가 가장 중요합니다. 자료를 받기 전에는 같은 모양의 가상 데이터로 1단계를 만듭니다.
